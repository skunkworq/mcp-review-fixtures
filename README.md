# Gamma Systems MCP review fixtures

Synthetic examples for reviewing plugins published by Ben Ebsworth, Gamma Systems Pty Ltd.

The Cuttlefish workflows are manual fixtures. One prints a success message; the other intentionally exits with code 13 so reviewers can inspect a real failed attempt and its bounded logs. They run only when an operator explicitly starts them in the isolated `openai-mcp-review` project.

Reviewer accounts receive access to sample workspaces. Credentials are supplied through OpenAI's secure reviewer fields. Recorded walkthroughs will be attached to a release only after playback and content checks; no recording is claimed by this source.
